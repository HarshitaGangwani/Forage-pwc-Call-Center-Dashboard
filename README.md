# Forage-pwc-Call-Center-Dashboard
Power BI dashboard analyzing call center performance metrics, built as part of the PwC Power BI Job Simulation (Forage)
This project is a Power BI dashboard built as part of PwC's Power BI Job Simulation on Forage. It analyzes call center performance across employees, tracking metrics like calls answered, calls resolved and customer satisfaction. The dashboard is designed to give a clear, interactive view of individual and overall performance to support operational and staffing decisions.
